# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities through GitHub's private vulnerability reporting:

**Security tab → Report a vulnerability**

Do not open a public issue for security reports. Private reporting ensures the issue can be discussed and fixed before public disclosure.

## What to include

- Description of the vulnerability
- Steps to reproduce
- Affected versions or components
- Potential impact

## Response

You can expect an initial response within 72 hours. Fixes will be released as patch versions.
